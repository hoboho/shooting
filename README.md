# شوتینگ (Shooting)

برنامهای **مستقل، کاملاً آفلاین و فارسیزبان** برای ثبت، مدیریت و گزارشدهی عملیات
شوتینگ (کابلکشی فیبر نوری) روی اندروید. این مخزن یک اپلیکیشن مستقل است و هیچ
وابستگی به پروژهٔ Metra یا کتابخانه/ماژول/بکند آن ندارد؛ Metra فقط **مرجع طراحی
بصری و تجربهٔ کاربری** بوده است (رنگها، تایپوگرافی Vazirmatn، چیدمان RTL،
کامپوننتها، تقویم جلالی، قالببندی اعداد و سبک گزارش PDF).

- نام بسته: `ir.hoboho.shooting` · مخزن: `hoboho/shooting`
- زبان رابط: فارسی (`localeFilters=fa`) · تاریخ: هجری شمسی · پول: **تومانِ عدد صحیح**
- بدون حساب کاربری، بدون احراز هویت، بدون سرور/فضای ابری، بدون آنالیتیکس، بدون
  مجوز `INTERNET`. پایگاه دادهٔ Room روی خود دستگاه تنها منبع حقیقت است.

## قابلیتها

| بخش | توضیح |
| --- | --- |
| پروژهها | نام، محدوده کار، کارفرما، سرپرست، توضیحات، فعال/غیرفعال (بایگانی)، ویرایش |
| گزارش روزانه | بهازای هر پروژه و تاریخ؛ اطلاعات پروژه بهصورت پیشفرض و **قابل ویرایش**؛ تعداد کارگران (پیشفرض ۰)، یادداشتها؛ جلوگیری از گزارش تکراری همان پروژه/تاریخ |
| عملیات شوتینگ | چند عملیات در هر روز؛ نوع/کد نقطه شروع و پایان (`ODC`, `FAT`, `حوضچه`, `منهول`)، کنتور شروع/پایان، نوع کابل قابلانتخاب؛ **`L = \|endMeter − startMeter\|`** (اختلاف منفی مجاز است)؛ افزودن/ویرایش/حذف سریع |
| خلاصه روز | فقط **جمع طول شوتینگ روز** (بدون تعداد عملیات/تفکیک کابل)؛ بازگشایی و ویرایش گزارش |
| هزینههای شرکت | مبالغ **دریافتنی از کارفرما/شرکت** (نه هزینه شخصی، نه حقوق و دستمزد، نه مالیات، نه بودجهبندی)؛ دستههای قابلگسترش؛ مبلغ صحیح تومان، شرح، مرجع رسید/پیوست، ارتباط اختیاری با پروژه/گزارش روزانه |
| تسویهها | چند تسویه برای هر هزینه؛ «تسویهنشده / جزئی / کامل»؛ `مانده = مبلغ هزینه − جمع تسویهها`؛ جلوگیری از ثبت تسویه بیش از مانده |
| گزارشها | گزارش روزانه، گزارشدورهای (بازه تاریخ + فیلتر پروژه)، گزارش هزینهها و تسویهها؛ طولها و مبالغ **هرگز** با هم جمع یا ترکیب نمیشوند |
| خروجی PDF | A4 فارسی RTL، فونت Vazirmatn، ارقام فارسی، تاریخ جلالی، تومان، سرستونهای تکرارشونده، شماره صفحه؛ سه نوع گزارش |
| پشتیبانگیری | قالب نسخهدار + بررسی یکپارچگی SHA-256، پیشنمایش، سه راهبرد صریح بازیابی، نسخهٔ ایمنی پیش از هر بازیابی، بدون جایگزینی خاموش |

دادههای مرجع (کور کابل `۶/۱۲/۲۴/۴۸/۹۶/۱۴۴ Core` و هفت دستهٔ هزینه) ردیفهای
معمولی پایگاه دادهاند؛ افزودن/غیرفعال کردن آنها نیازی به تغییر اسکیما ندارد.

## معماری در یک نگاه

```
app/src/main/java/ir/hoboho/shooting/
├── core/       تاریخ جلالی، قالببندی، مدل/موتور PDF، JSON/نگاشت/مدیریت پشتیبان، اشتراکگذاری
├── domain/     مدلها، اعتبارسنجی، محاسبات، تجمیع دورهای، ساخت مشخصات گزارش
├── data/       موجودیتها/DAOهای Room، نگاشتها، پیادهسازی مخازن
├── di/         ماژولهای Hilt، مهاجرتها، Seed اولیه
├── ui/         تم Material 3 همسان با Metra، کامپوننتها، ناوبری
└── feature/    داشبورد، پروژهها، گزارشهای روزانه، هزینهها، گزارشها، تنظیمات/پشتیبان
```

جریان اصلی: **پروژه → گزارش روزانه → افزودن عملیات (طول خودکار) → ذخیره →
ثبت هزینه/تسویه → مشاهده گزارشها و مانده مطالبات.**

جزئیات بیشتر: [معماری](docs/ARCHITECTURE.md) · [مدل داده](docs/DATA_MODEL.md) ·
[ساخت](docs/BUILD.md) · [آزمونها](docs/TESTING.md) ·
[پشتیبانگیری و PDF](docs/BACKUP_AND_PDF.md) · [وضعیت کنترل کیفیت](docs/QA.md).

## ساخت و اجرا

نیازمندیها: **JDK 21**، Android SDK (platform 37، buildtools)، Gradle 9.6.0 از
طریق wrapper موجود. هیچ کلید/توکن/سرویس ابری لازم نیست.

```bash
git clone https://github.com/hoboho/shooting.git
cd shooting
./gradlew :app:assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest      # ۶۲ آزمون JVM
./gradlew :app:lintDebug              # تحلیل ایستا
./gradlew :app:connectedDebugAndroidTest  # آزمونهای Room و جریانهای کاری روی دستگاه/امولاتور
```

`README` و مستندات دقیقتر در [docs/BUILD.md](docs/BUILD.md) و
[docs/TESTING.md](docs/TESTING.md). گردشکار GitHub Actions در
[`.github/workflows/android.yml`](.github/workflows/android.yml) همان دستورات را
اجرا میکند و APK، گزارش آزمون/لینت و اسکیمای Room را بهعنوان artifact بارگذاری
میکند و سه نمونهٔ PDF تولیدشده در آزمون جریان کاری را نیز با artifact
`qa-pdf-samples` بارگذاری مینماید. اجراهای
[PR 41480196402](https://github.com/hoboho/shooting/actions/runs/41480196402) و
[push 41480188364](https://github.com/hoboho/shooting/actions/runs/41480188364)
بهعنوان اجراهای مرجع تأیید ساخت، هر سه job را با `success` به پایان رساندند؛ جزئیات پایدار
در [وضعیت کنترل کیفیت](docs/QA.md) قابل مشاهده است.

### اجرا بدون Gradle (محیط آفلاین)

دو ابزار کمکی وجود دارند که بدون Android SDK اجرا میشوند:

```bash
python3 scripts/check_sources.py                 # بررسی منابع، importها، ناوبری، قواعد حیاتی
KOTLINC=/path/to/kotlinc bash scripts/run-offline-tests.sh  # آزمونهای خالص Kotlin
KOTLINC=/path/to/kotlinc COROUTINES_JAR=/path/to/kotlinx-coroutines-core-jvm.jar \
  bash scripts/offline-compile-check/run.sh   # کامپایل ۴۲ فایل core/domain/data/di با استاب
```

دومی همان ۱۳ فایل آزمون `app/src/test` را با یک اجراکنندهٔ بازتابی کوچک اجرا
میکند؛ در Gradle این آزمونها بدون تغییر با JUnit واقعی اجرا میشوند. **این ابزارها
جایگزین کامپایل اندروید، لینت یا ساخت APK نیستند.**

## وضعیت تأیید (مهم)

اجراهای مرجع تأییدشدهٔ [PR 41480196402](https://github.com/hoboho/shooting/actions/runs/41480196402)
و [push 41480188364](https://github.com/hoboho/shooting/actions/runs/41480188364)
با نتیجهٔ `success` برای هر سه job به پایان رسیدند. اجرای
قدیمی [41394294285](https://github.com/hoboho/shooting/actions/runs/41394294285)
همچنان مرجع نخستین ساخت کامل است؛ کامیتهای بعدی همان گردشکار را روی push/PR
اجرا میکنند.

| مورد | وضعیت |
| --- | --- |
| آزمونهای منطق خالص JVM | ✅ اجرا و عبور: **۶۲ از ۶۲** (harness آفلاین)؛ `testDebugUnitTest` نیز در CI عبور کرد |
| بررسیهای ایستای `check_sources.py` | ✅ اجرا و عبور: ۰ خطا (محلی و job نخست CI) |
| کامپایل ۴۲ فایل `core/domain/data/di` با `kotlinc` واقعی + استاب API | ✅ اجرا و عبور: `exit 0` (کمکی، نه کامپایل اندروید) |
| کامپایل منابع اندروید/Compose/Room/Hilt/KSP، `lintDebug`، `assembleDebug` و خروجی اسکیمای Room | ✅ اجرا و عبور در job دوم CI؛ APK و گزارشها بهعنوان artifact بارگذاری شدند |
| آزمونهای instrumentation Room/اسکیما و جریانهای کاری روی امولاتور API 34 | ✅ **۱۲ آزمون** در job سوم CI: `tests="12" failures="0" errors="0" skipped="0"`؛ شامل رندر خودکار هر سه PDF و artifact نمونهها |
| اسکیمای نسخهٔ ۱ و سیاست مهاجرت | ✅ شکل v1 روی SQLite واقعی بررسی و JSON توسط KSP تولید/بارگذاری شد؛ نسخهٔ فعلی v1 است و مهاجرتی وجود ندارد |
| بازبینی بصری صفحات و PDF، اجرای دستی جریان روزانه/هزینه/تسویه/پشتیبان، حالت تاریک و چرخش | ⏳ انجام نشده؛ چکلیست دقیق در [QA](docs/QA.md) |

در محیط توسعهٔ محلی همچنان `./gradlew` بهدلیل نبود Android SDK و عدم دسترسی به
مخازن Gradle قابل اجرا نیست؛ اجراهای اندرویدی فوق روی runner دارای SDK انجام
شدهاند. این موفقیت فقط **ساخت و آزمونهای خودکار** را اثبات میکند و بهمعنای
تأیید کیفیت بصری، جریانهای دستی یا «آمادهٔ انتشار» بودن اپلیکیشن نیست.
