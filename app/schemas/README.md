# Room schema exports

`app/build.gradle.kts` sets `ksp { arg("room.schemaLocation", "$projectDir/schemas") }`
and `exportSchema = true`, so every `:app:kspDebugKotlin` run writes a versioned
JSON schema here, under
`ir.hoboho.shooting.data.local.ShootingDatabase/<version>.json`.

Version 1 is the initial release. The JSON file for it is generated by Room's
annotation processor (it contains Room's computed `identityHash`, so it is
intentionally **not** hand-authored). CI uploads the generated directory as the
`room-schema` artifact; commit the generated file together with the first
schema-changing change.

## Migration policy

* `fallbackToDestructiveMigration()` is never used (see `di/Migrations.kt`).
* Every future schema change must add an explicit, additive `Migration` to
  `Migrations.ALL` and a matching `MigrationTestHelper` case in
  `app/src/androidTest` that starts from the committed previous-version JSON.
* The on-device `DatabaseSchemaTest` verifies the v1 table/column/index shape
  so an accidental schema change cannot ship unnoticed.
